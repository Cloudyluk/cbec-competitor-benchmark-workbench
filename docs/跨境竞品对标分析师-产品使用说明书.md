# 跨境竞品对标分析师 产品使用说明书

## 一、产品职位定位

**产品名称**：跨境竞品对标分析师

**英文名**：CBEC Competitor Benchmark Analyst

**一句话定位**：

一个面向跨境电商公司的 AI 竞品对标分析师，帮助运营、产品、类目和管理层调研竞品，量化自身差距，并输出 30/60/90 天能力提升计划。

它不是普通资料搜索助手，而是一个虚拟岗位。

## 二、虚拟岗位说明

### 岗位名称

跨境竞品对标分析师

### 主要职责

- 调研竞品品牌、店铺、独立站、产品、渠道和内容策略
- 核验竞品真实身份，避免品牌、店铺、公司主体混淆
- 建立证据账本，区分已核验、较可靠、仅供参考、待核实、冲突信息
- 对标本公司在产品、运营、内容、投放、品牌、供应链等方面的能力
- 输出能力评分卡、差距分析和量化提升目标
- 给出 30/60/90 天行动计划，帮助公司持续提升综合竞争力

### 适合使用者

- 跨境电商老板
- 运营负责人
- 类目负责人
- 产品开发/选品负责人
- Amazon、TikTok、Shopee、Lazada 等平台运营
- 独立站运营
- 品牌负责人
- 市场调研/竞品分析人员

## 三、产品介绍

跨境竞品对标分析师是一款面向跨境电商公司的 AI 分析工具。

它可以帮助用户快速调研竞品，识别竞品优势，量化本公司差距，并生成可执行的提升计划。

它重点回答三个问题：

1. 这个竞品是谁？
2. 它在哪些方面比我们强？
3. 我们接下来 30/60/90 天应该怎么提升？

## 四、适用场景

本产品适合以下场景：

- 调研某个竞品品牌
- 分析 Amazon、TikTok Shop、Shopee、Lazada、eBay、Walmart 等平台店铺
- 对标类目头部品牌
- 分析竞品独立站和社媒内容
- 研究竞品产品组合、价格带和卖点
- 对比本公司与竞品的运营能力
- 制定季度增长计划
- 辅助选品、产品升级、内容优化、广告投放和品牌建设

## 五、不适用场景

本产品不适合直接替代：

- 专业法律意见
- 财务审计
- 投资尽调报告
- 平台后台真实数据
- 公司内部经营决策审批

它提供的是调研辅助和经营建议，最终决策仍需结合公司内部数据和负责人判断。

## 六、输入内容

用户可以输入以下任意一种信息：

- 竞品品牌名
- 竞品公司名
- Amazon 店铺链接
- TikTok Shop 店铺名
- Shopee、Lazada、eBay、Walmart 店铺
- 独立站网址
- ASIN、SKU、商品链接
- 竞品直播间或社媒账号
- 想对标的类目头部品牌

### 输入示例

```text
调研 JISULIFE 几素，帮我们做竞品对标，看看我们公司在产品、内容、渠道和品牌上差在哪里。
```

```text
分析这个 Amazon 店铺，判断它有哪些值得我们学习的地方，并给出 90 天提升计划。
```

```text
对标 Anker，帮我们整理它的渠道、产品矩阵、品牌能力和我们可以量化提升的方向。
```

## 七、输出内容

产品默认输出以下内容。

### 1. 竞品身份确认

包括：

- 品牌名
- 公司主体
- 店铺、网站或账号
- 母公司或关联公司
- 需要排除的同名主体
- 身份是否已核验

### 2. 竞品核心优势

包括：

- 产品组合
- 价格带
- 渠道布局
- 平台运营
- 独立站能力
- 内容与素材
- 广告投放
- 社媒/KOL
- 品牌信任
- 履约与售后

### 3. 能力评分卡

系统会围绕以下能力项打分：

| 能力项 | 说明 |
|---|---|
| 产品组合 | SKU、价格梯度、差异化、认证 |
| 平台运营 | 店铺质量、Listing、评论、促销 |
| 独立站 | 官网体验、信任模块、转化路径 |
| 内容能力 | 图片、视频、UGC、达人素材 |
| 广告增长 | 投放渠道、素材、落地页、优惠 |
| 社媒社区 | 账号矩阵、互动、粉丝质量 |
| 定价促销 | 价格带、优惠节奏、组合销售 |
| 供应链履约 | 发货、退货、仓储、售后 |
| 品牌信任 | 认证、保修、媒体、用户口碑 |
| 数据管理 | KPI、复盘、测试、反馈机制 |

评分方式：

- 1 分：明显落后
- 2 分：基础薄弱
- 3 分：行业平均
- 4 分：较强
- 5 分：优秀，值得重点学习

### 4. 差距分析

输出：

- 竞品评分
- 我方评分
- 差距
- 优先级
- 证据来源
- 是否可复制
- 需要本公司补充的数据

### 5. 30/60/90 天提升计划

系统会给出：

- 30 天内可以立即做的动作
- 60 天内需要组织协作的动作
- 90 天内需要形成体系的动作
- 每个动作对应负责人、交付物、KPI 和目标值

示例：

| 周期 | 动作 | KPI |
|---|---|---|
| 30 天 | 优化 Top 3 SKU Listing 图片和标题 | 转化率提升 10% |
| 60 天 | 建立短视频素材库，产出 30 条素材 | CTR 提升 15% |
| 90 天 | 搭建达人合作矩阵 | 达人内容贡献销售占比达到 10% |

## 八、使用流程

### 第一步：输入竞品对象

输入品牌、店铺、网址、商品链接或账号。

### 第二步：说明对标目标

例如：

- 我想提升产品能力
- 我想提升 Amazon 运营
- 我想提升独立站转化
- 我想学习竞品内容和投放
- 我想做年度战略对标

如果不说明，系统默认做综合能力对标。

### 第三步：补充本公司信息，可选

如果用户能提供本公司数据，结果会更准确。

可补充：

- 主营类目
- 目标市场
- 当前平台
- Top SKU
- 月销售额区间
- 广告渠道
- 团队规模
- 当前痛点

如果不提供，系统会先只评分竞品，并列出“需要本公司补充的数据”。

### 第四步：生成报告

系统输出：

- 对标结论
- 竞品证据
- 能力评分卡
- 差距分析
- 量化提升计划

### 第五步：执行与复盘

用户可以按 30/60/90 天计划执行，并定期重新对标。

## 九、推荐使用频率

- 重点竞品：每月复盘一次
- 类目头部品牌：每季度复盘一次
- 新品开发前：每次立项前使用
- 广告/内容策略调整前：每次大改版前使用
- 年度战略规划：每半年或每年使用一次

## 十、最佳使用方式

不推荐只问：

```text
帮我查一下这个竞品。
```

推荐这样问：

```text
帮我调研 JISULIFE 几素，重点分析它的产品组合、内容能力、平台运营和品牌信任。
我们是一家做便携小家电的跨境公司，请对标我们的综合能力，输出评分卡和 90 天提升计划。
```

## 十一、产品价值

这个产品最终帮助公司做到：

- 从“凭感觉看竞品”变成“有证据地对标竞品”
- 从“知道别人强”变成“知道我们差在哪里”
- 从“泛泛建议”变成“可量化、可执行、可复盘的提升计划”
- 从单次调研变成持续提升公司综合能力的经营工具

## 十二、最终定位

它可以被包装成一个 AI 岗位：

> 跨境竞品对标分析师：负责持续研究竞品、量化公司能力差距，并推动运营、产品、内容、品牌和供应链的系统性提升。
