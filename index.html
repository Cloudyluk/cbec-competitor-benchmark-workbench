使用说明

普通用户流程

怎么用

  • 先在 API 连接配置里填写兼容 OpenAI 的接口信息。
  • 填写竞品名称、目标市场、产品类目和本公司信息。
  • 选择对标维度，点击一键生成报告。
  • 检查结果后下载 Markdown 或 PDF。

安全提示

  • API Key 只保存在本机浏览器 localStorage。
  • 纯前端工具会直接从浏览器请求你填写的 API Base URL。
  • 企业团队正式使用时，建议后续升级为本地代理或后端版本。

报告用途

  • 竞品月度复盘
  • 新品立项前对标
  • 运营/内容/投放提升计划
  • 管理层季度能力评估
