# 对象身份核验与同名消歧

跨境电商调研中最高频的严重错误，是**查错了对象却给出了看似完整的报告**。本文档定义身份锁定流程。

## 为什么跨境电商特别容易搞错

1. **一主体多店铺**：一家深圳公司运营 20-200 个 Amazon 店铺是常态（"铺货型/精品矩阵"），店铺之间表面无关联。
2. **一店铺多主体**：店铺可转让、可代运营、可租用他人执照注册。当前显示主体未必是实际控制人。
3. **品牌 ≠ 商标持有人**：品牌名归属常挂在法人个人、香港离岸公司或代持公司名下，与运营主体分离。
4. **同名公司泛滥**：中文公司名重名率极高（"XX科技有限公司"），且深圳/香港/开曼三地常有同名或近名关联体。
5. **展示名与登记名不一致**：Amazon 店铺展示名是可随时修改的商号，"Detailed Seller Information" 里的 Business Name 才是登记名。
6. **品牌词与通用词冲突**：很多跨境品牌是生造词或常见英文单词，搜索会大量污染。

## 身份卡字段（P1 必填）

| 字段 | 说明 | 最低证据要求 |
|---|---|---|
| `primary_id` | 唯一标识符：统一社会信用代码 / 公司注册号 / Seller ID / ASIN / 商标注册号 / 域名 / LEI | VERIFIED（门禁） |
| `legal_name` | 官方登记名称（原文，含语言） | VERIFIED（门禁） |
| `display_name` | 平台展示名 / 商号 | VERIFIED |
| `brand_names[]` | 关联品牌名及各自商标状态 | ≥STRONG |
| `entity_type` | 公司/店铺/商品/供应商/品牌/账号 | — |
| `jurisdiction` | 注册法域（国家+省/州） | VERIFIED |
| `incorporated_at` | 成立/注册日期 | VERIFIED |
| `status` | 存续/注销/吊销/迁出 | VERIFIED |
| `parent_chain[]` | 运营主体 → 中间持股 → 最终母公司 | ≥STRONG，逐层标注 |
| `affiliates[]` | 已识别的关联主体（同法人/同地址/同电话/同商标） | ≥STRONG，注明关联依据 |
| `platform_presence[]` | 各平台店铺/账号及其 ID | VERIFIED |
| `domains[]` | 独立站与官网域名 | VERIFIED |
| `excluded_entities[]` | **排除清单**：被排除的同名/近名实体及区分依据 | 必填，不得为空说明"未发现同名" |

## 消歧操作手册

### Amazon 店铺 → 运营主体

1. 打开店铺页 → `Detailed Seller Information` / 「卖家详细信息」。字段包含 Business Name、Business Address、有时含营业执照号或 VAT 号。这是**平台一手来源（L2）**，可标 VERIFIED。
2. 用 Business Name 回查工商登记（中国企业查 gsxt.gov.cn，香港查 ICRIS，美国查对应州 SoS）。
3. 注意：Business Address 大量为注册代理地址或虚拟办公室。地址相同不等于同一实体，但**地址+电话+法人任两项相同**可作为关联依据（STRONG）。
4. 反向找矩阵店铺：用 Business Name 或地址在搜索引擎与卖家数据工具中反查其他店铺；用商标持有人反查其名下全部品牌与备案店铺。

### 独立站 → 所有者

1. 站点底部的 Terms / Privacy / Imprint / Contact 页，欧盟站点受法律强制要求披露运营方（Impressum），信息质量高。
2. WHOIS（多数已隐私保护，但注册时间、注册商、NS 仍有价值）。
3. 技术指纹：Shopify 站可试 `/products.json`、`/sitemap.xml`、`/cart` 判断平台；BuiltWith / Wappalyzer 看技术栈；Google Analytics / Facebook Pixel ID 相同可关联同一运营方（STRONG）。
4. 支付与收款主体：结账页显示的收款方名称往往是真实登记主体。
5. 商标与版权声明中的公司名。

### 品牌 → 商标持有人

- 美国：USPTO TSDR / Trademark Search，查 Owner、注册日、类别、状态、是否有异议或撤销。
- 中国：中国商标网 sbj.cnipa.gov.cn。
- 欧盟：EUIPO eSearch plus。
- 全球：WIPO Global Brand Database。
- Amazon Brand Registry 状态无法直接公开查询，但可从 Listing 是否有 A+ 内容、品牌旗舰店、Transparency 标签间接推断（STRONG 上限）。

### 供应商/工厂 → 真实产能主体

- 1688 / Alibaba.com 旺铺的「企业认证」「实力商家」信息 → 回查工商。
- 区分**工厂**与**贸易公司**：查经营范围是否含生产制造、是否有排污许可/生产许可、社保人数、厂房产权或租赁、以及海关进出口收发货人备案。
- ImportYeti 等提单数据反查其海外买家，可验证是否真有出口业务。

### 同名实体判别

建立排除清单时，逐一记录区分依据。常用区分维度：

| 维度 | 用法 |
|---|---|
| 统一社会信用代码 / 注册号 | 唯一，最强 |
| 成立日期 | 相差数年即不同实体 |
| 法定代表人/董事 | 需注意常见姓名 |
| 注册地址 | 相同地址可能只是同一代理 |
| 经营范围 | 跨境电商 vs 完全无关行业 |
| 商标类别 | 不同尼斯分类下同名品牌可合法共存 |
| 域名注册时间与内容 | 判断是否为品牌官网 |

**输出要求**：排除清单每一项写成 `<被排除实体名> | <唯一标识> | <排除依据> | <来源URL>`。

## 门禁检查

进入 P2 之前自检：

- [ ] `primary_id` 与 `legal_name` 均为 VERIFIED
- [ ] `excluded_entities[]` 已填写（若确实无同名，写"已检索 X 渠道未发现同名实体"并附检索式）
- [ ] `parent_chain[]` 至少标注到已知最上层，未知处显式写"未追溯到"
- [ ] 若调研对象是店铺/商品，已明确其**运营主体**；若无法确定，在报告开头显著位置声明该限制

任一项不通过 → 停止分析，向用户回报歧义与候选清单，请求确认后再继续。
