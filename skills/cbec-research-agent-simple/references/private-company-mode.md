# 私有公司 / 中小卖家模式（Private-Company Mode）

本模式解决：当调研对象是**未上市、无公开审计财报、无定期披露**的私有跨境企业 / 中小卖家时，
直接套用上市公司工作流会产生两类误判——① 把"没有 VERIFIED 财务"当成致命缺陷、② 身份核验
因品牌名↔公司名错位而把错误主体当标的。本模式给出差异化的预期、证据口径与决策语言。

> 启用方式：`ledger_check.py --mode sme`。P0 需求澄清时若确认对象为私有/未上市主体，全程按本模式执行。

---

## 一、与标准模式的差异（速查）

| 环节 | 标准模式（上市公司） | 私有公司模式（SME） |
|---|---|---|
| P0 数据预期 | 默认能拿到 L1 审计年报 | **默认拿不到**，营收/GMV 封顶 WEAK/UNVERIFIED |
| P1 身份核验 | 工商与年报一致，较易 | **最关键**：品牌名/公司名/英文名三套错位，须先映射（见 `brand-entity-map.md`） |
| P2 来源重心 | L1 年报 + L2 平台 | **L3 媒体 + L4 工具 + L2 平台一手**，无 L1 财务 |
| P3 定级 | 财务可 VERIFIED | 财务类事实**强制 WEAK 上限**（除非主体自述后台截图等 L2 级一手数据） |
| P3 新鲜度锚 | 财报披露日 | **媒体报道日 / 工具抓取日**（`reported_at`，见 `freshness-policy.md` 第六节） |
| P4 渠道/曝光/参考价值 | 适用 | **最适用**（DTC 独立站品牌，数据更易得） |
| P5 决策语言 | 缺 VERIFIED 财务 → 补充尽调 | 缺 VERIFIED 财务属**预期内**，封顶由"补充尽调"降为"谨慎通过"，并明确标注"未上市无审计源" |
| P6 报告 | 列审计源 | **必须声明**：未上市、无审计财务、数据来自媒体/工具估算 |

## 二、P0：澄清数据可得性预期

进入 P1 前，向用户明确：

> 该主体为未上市私有企业，**没有公开审计财报**。本次能给出的营收/GMV 均为媒体盘点或第三方工具
> 估算（WEAK 级），不能作为精确数字；身份核验（品牌↔公司映射）将是本报告最关键的环节。

若用户坚持要 VERIFIED 级财务，须引导其提供：主体自述后台截图、投资人数据室、或付费商业数据库（如 PitchBook/企查查 pro），并在账本标 L2 + 注明来源性质。

---

## 三、P1：品牌↔公司映射先行（本模式核心）

私有跨境企业的"品牌名、公司名、英文名"三套体系常互相错位，典型陷阱见 `brand-entity-map.md`：
- **VANKYO** = 万拓科创（VanTop）子品牌，与"万播科技/WANBO"是两家公司，须拆开；
- **Lofree/洛斐** 天眼查"洛斐(深圳)科技"是 50 万注册资本壳，真实运营主体须 P1 精准锁定；
- 英文名与中文名无字面关联（如 Fosi Audio ↔ 深圳远虑科技）。

P1 门禁在 SME 模式下**不可跳过**：`brand_names[]` 与 `legal_name` 的映射关系须有证据（商标持有人、
招聘主体、收款方、媒体股权报道），并在 `excluded_entities[]` 列出被排除的同名/壳实体。

---

## 四、P3：财务事实强制降级与口径

SME 模式下，来源为 L3/L4 且内容为营收/GMV/净利等财务指标的，账本最高标 **WEAK**：
- 媒体盘点（亿邦/36氪/锦品出海）→ L3 → WEAK；
- SimilarWeb/工具估算 UV/GMV → L4 → WEAK，并强制 `metric_type` + `reported_at`；
- 主体自述（招商材料/直播间口播）无第三方佐证 → UNVERIFIED；
- 若两源口径冲突（如 A 媒说 1 亿、B 媒说 1.2 亿）→ CONFLICT，须双向链接。

---

## 五、P5：决策语言差异

`ledger_check.py --mode sme` 调整决策上限逻辑：
- CONFLICT / STALE 核心事实 → 仍**补充尽调**（真实问题不豁免）；
- 核心类别 `financial`/`operational` **仅因缺 VERIFIED**（已有 WEAK/L4 估算）→ 封顶降为**谨慎通过**，
  原因标注"未上市，官方财务不可达，VERIFIED 不可达属预期"。
- 仍输出黄旗 Y29/Y30 提醒数据时效与证据强度。

> 设计意图：避免 SME 标的被"上市公司标准"一刀切打成补充尽调，同时不掩盖真实风险（冲突、过期仍封顶）。

---

## 六、P6：报告必要声明

报告"方法与局限"段必须包含：

> 本主体为**未上市私有企业**，无公开审计财报。本报告营收/GMV 数据来自媒体盘点与第三方工具估算（WEAK 级），
> 仅代表数量级，不作为精确依据；身份核验已通过品牌↔公司映射锁定运营主体（见 P1 身份卡）。

## 七、与已有模块的关系

- `entity-resolution.md`：本模式的 P1 是其特例（错位更严重），映射案例库见 `brand-entity-map.md`。
- `freshness-policy.md`：本模式的数据锚从"财报日"转为"媒体/工具日"，见其第六节 `reported_at`。
- `decision-rubric.md`：本模式仅调整决策语言，红旗/黄旗清单不变。
