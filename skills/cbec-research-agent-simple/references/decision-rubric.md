# 决策判定规则（五档）

## 判定顺序

```
1. 检查红旗 → 命中任一 → 淘汰（终止，不再继续打分）
2. 检查核心事实证据等级 → 存在 UNVERIFIED 或 CONFLICT → 补充尽调（冲突处置与跨源定级矩阵见 `references/conflict-resolution.md`）
3. 检查核心事实时效 → 任一核心类别存在 STALE 事实（data_as_of 超阈值）→ 补充尽调
4. 检查时点性障碍 → 存在 → 暂缓
5. 统计黄旗 → 0-1 且有缓解措施 → 通过；2-3 → 谨慎通过；≥4 → 补充尽调或暂缓
```

> 第 3 步的时效闸门与新鲜度分级见 `references/freshness-policy.md`：fast 指标 >180 天、medium >365 天、slow >730 天即 STALE；STALE 的核心事实不降级但会把决策上限压到"补充尽调"，且计为黄旗 Y29。设计意图是**过期数据不能悄悄进入"通过"**。

## 核心事实清单（按场景）

"核心事实"指该项若不成立，结论就会翻转。这些必须达到 VERIFIED，否则决策上限为「补充尽调」。

| 场景 | 核心事实 |
|---|---|
| 采购选品 | 类目准入要求、强制认证清单、专利与商标壁垒、目标价格带与主要竞品价格、平台佣金与物流成本 |
| 供应商准入 | 主体存续与真实性、生产资质（是工厂还是贸易商）、产能、强制认证、有无制裁/清单命中、历史质量事故 |
| 竞品分析 | 竞品运营主体、店铺与账号归属、可比性依据、核心数据口径 |
| 客户评价洞察 | 评价样本来源与抽样方式、样本量、时间窗 |
| 商品内容生成 | 每条卖点的参数/认证/证据来源、目标市场合规要求 |
| 直播话术辅助 | 产品事实与认证、平台话术禁区、比较宣称的数据来源 |
| 投融资初筛 | 主体与股权结构、收入口径与真实性、平台依赖度、合规与诉讼状态、资金往来合规性 |
| 风险预警 | 命中清单情况、诉讼状态、召回与安全通报、认证有效性 |

## 红旗（一票淘汰）

| # | 红旗 | 核验来源 |
|---|---|---|
| R1 | 主体或关联方命中 OFAC SDN List | OFAC 官网 |
| R2 | 命中 BIS Entity List / Denied Persons List | BIS 官网 |
| R3 | 命中 UFLPA 涉疆实体清单，或供应链可追溯至清单实体 | DHS UFLPA Entity List |
| R4 | ITC Section 337 调查在案且指向本方产品 | USITC |
| R5 | 存在未和解的批量商标/专利侵权诉讼（尤其 N.D. Illinois Schedule A 类），或资金已被冻结 | CourtListener / 法院文书 |
| R6 | 强监管品类缺失强制认证且无整改计划（儿童用品 CPC、电子 FCC/CE、化妆品 FDA/CPNP、医疗器械、食品接触材料、锂电池 UN38.3） | 各监管机构 |
| R7 | 主体无法核验：查无此公司、已注销/吊销、明显空壳（无社保、无实际经营地址、无出口记录） | 工商 + 海关 |
| R8 | 有产品召回或严重安全事故史且无整改证据 | CPSC / RAPEX |
| R9 | 主体或实控人涉严重失信、刑事案件、集资类风险 | 信用中国 / 裁判文书 |
| R10 | 明确的数据造假证据（伪造认证证书、伪造检测报告、伪造平台后台截图） | 交叉核验 |

红旗必须由 VERIFIED 级证据支撑。若仅有 WEAK 证据指向红旗，结论应为「补充尽调」而非「淘汰」，并把核实该红旗列为第一优先尽调问题。

## 黄旗（累计计数）

**主体与治理**
- Y01 成立不足 12 个月
- Y02 近 12 个月内运营主体或股东发生重大变更
- Y03 注册资本大幅减资，或认缴长期未实缴
- Y04 关联企业众多且业务重叠（矩阵化，风险隔离意图明显）
- Y05 注册地址为虚拟办公室/集群注册且无实际经营证据

**经营与依赖**
- Y06 单一平台销售占比 >70%
- Y07 单一站点/市场占比 >80%
- Y08 单一客户占比 >50%
- Y09 单一供应商占比 >70% 且无备选
- Y10 提单/出货数据近 6 个月持续下滑

**产品与合规**
- Y11 强制认证已有但即将到期或覆盖型号不全
- Y12 欧盟市场无 EU Responsible Person / 未完成 EPR 登记（GPSR 生效后为高危）
- Y13 类目存在活跃专利权人，历史有维权记录
- Y14 品牌未注册商标或商标处于异议/驳回状态
- Y15 产品有安全投诉记录（SaferProducts 投诉但未召回）

**店铺与内容**
- Y16 评价真实性存疑（时间聚集、措辞雷同）
- Y17 差评率高于类目均值，且主因指向质量或安全
- Y18 存在 Listing 劫持、跟卖纠纷、变体滥用
- Y19 曾被平台处罚、下架、限制销售
- Y20 广告依赖度极高（自然流量占比极低）

**财务与资本**
- Y21 收入口径不清或多处披露不一致
- Y22 毛利率显著偏离类目常态（过高需验真，过低难持续）
- Y23 存货与销售增速严重背离
- Y24 融资信息与工商登记不一致
- Y25 收款通道不稳定或曾被冻结

**信息质量**
- Y26 关键信息大量依赖主体自述
- Y27 多个来源存在未解决的冲突
- Y28 重要来源不可达且无替代路径
- Y29 关键时效指标陈旧：核心类别存在 STALE 事实（data_as_of 超过新鲜度阈值，详见 `references/freshness-policy.md`）

## 绿旗（可用于抵消黄旗，需 VERIFIED）

- G1 海关 AEO 高级认证
- G2 自有商标已核准且覆盖主要目标市场类别
- G3 有正规第三方验厂报告（BSCI / Sedex / SGS / 客户验厂）
- G4 强制认证齐备且在有效期内，覆盖全部在售型号
- G5 多平台+独立站均衡布局，无单点依赖
- G6 连续 24 个月以上稳定出货记录
- G7 有可核验的知名品牌客户
- G8 上市公司或有正规机构融资背书
- G9 评价长期稳定在类目前列且无真实性疑点

**抵消规则**：1 个绿旗可抵消 1 个同领域的黄旗（例如 G4 可抵消 Y11），跨领域不可抵消。抵消后仍需在报告中保留原黄旗记录。

## 五档定义与必附内容

| 决策 | 必附内容 |
|---|---|
| **通过** | 支撑理由（fact_id）· 复评触发信号 · 建议的常规监控频率 |
| **谨慎通过** | 全部黄旗清单 · **可执行的附加条件**（如"首单不超过 X、账期改为验货后付、要求提供 CPC 证书原件、约定质量赔付条款"）· 条件验证方式 · 复评时点 |
| **补充尽调** | 缺口清单（哪些核心事实未达 VERIFIED）· 每个缺口的取证路径与预计难度 · 取证后可能的结论分支 |
| **暂缓** | 障碍是什么 · 解除条件 · 预计时点 · 期间监控什么 |
| **淘汰** | 命中的红旗及其 VERIFIED 证据 · 是否存在可修复路径（若有，说明修复后可重启评估的条件） |

## 场景权重差异

不同场景对同一黄旗的敏感度不同：

| 场景 | 加重关注 | 可适度放宽 |
|---|---|---|
| 采购选品 | Y13 专利壁垒、Y11/Y12 认证、R6 | Y01 成立时长 |
| 供应商准入 | Y09 供应商依赖、R3 UFLPA、R6 认证、G3 验厂 | Y06 平台依赖 |
| 竞品分析 | 信息质量类 Y26-Y28（结论用于自身决策） | 财务类 |
| 客户评价洞察 | Y16 评价真实性、Y17 差评率 | 主体治理类 |
| 内容生成/直播话术 | R6 认证、Y11、合规宣称红线 | 财务与资本类 |
| 投融资初筛 | 全部财务类 + Y06/Y07/Y08 依赖度 + R5 诉讼 | — |
| 风险预警 | 全部红旗 + Y11-Y15 + Y19 | — |

## 表述规范

结论段必须包含且仅包含一个决策词，格式：

> **决策：谨慎通过**
>
> 理由：核心事实已核验（F001、F003、F007 均为 VERIFIED）；识别到 3 项黄旗（Y06 平台依赖 87% [F012]、Y12 未完成德国 LUCID 登记 [F019]、Y17 差评率 8.2% 高于类目均值 4.1% [F024]），其中 Y12 可在 30 日内整改。
>
> 附加条件：①要求 30 日内提供 LUCID 注册号并复核；②首单量不超过 2000 件；③约定 DE 站上架前提供合规声明。
>
> 复评触发：平台依赖度、差评率月度监控；若差评率连续 2 月 >10% 立即复评。
