# 速查卡（一页纸）

> 不想读 15 份 reference 时，看这一页。详细规则仍在 `SKILL.md` 与各 `references/`。

## 1. 五级证据（结论置信度 = 支撑它的最弱一条关键证据）
| 等级 | 代码 | 怎么来的 | 上限 |
|---|---|---|---|
| 已核验 | VERIFIED | 1 个 L1/L2 官方/平台一手，或 ≥2 独立可信源一致；有 URL+访问日+原文 | — |
| 强推断 | STRONG | 单一 L3 权威二手，或多 L4 高度一致 | — |
| 弱推断 | WEAK | 单一 L4 / 工具估算 / 行业外推 / 单点样本 | 仅量级 |
| 未证实 | UNVERIFIED | 仅主体自述/宣传稿 | 不采信 |
| 冲突 | CONFLICT | ≥2 源互相矛盾，原样并列 | 不单方采信 |

**铁律**：第三方工具（Keepa/卖家精灵/Kalodata/SimilarWeb）估算**永不可标 VERIFIED**，最高 WEAK；数字无口径（时点/货币/含税）降一级；CONFLICT 不取平均。

## 2. 来源层级（采集优先级：前层 > 后层）
- **L1 官方登记**：工商/商标/海关/监管/交易所披露 → 可到 VERIFIED
- **L2 平台一手**：店铺页/商品页/评价/官方公告 → 可到 VERIFIED
- **L3 权威二手**：主流媒体/行业报告/年报引用 → STRONG
- **L4 工具/社区**：估算工具/论坛/Reddit → WEAK

## 3. 数据时效（联网核验 ≠ 数据最新）
每条数字事实必填 `data_as_of`（数据本身时点，非访问日）+ `metric_type`。
| metric_type | FRESH | AGED | STALE（压决策上限→补充尽调） |
|---|---|---|---|
| fast（月销量/粉丝/BSR/价格） | ≤90d | 91–180d | >180d |
| medium（季度营收/GMV） | ≤180d | 181–365d | >365d |
| slow（年度营收/净利） | ≤365d | 366–540d | >540d（>18mo） |
| structural/na（注册号/股权/定性） | 不参与 | — | — |

私有公司用 `reported_at`（媒体报道日）：距今 >365d 计 **Y30 知识陈旧**，提醒重搜。

## 4. 五档决策（必须且仅给一档）
| 决策 | 触发（概要） |
|---|---|
| **通过** | 核心事实全 VERIFIED，无红旗，黄旗 ≤1 有缓解 |
| **谨慎通过** | 核心 VERIFIED，2–3 黄旗，条件可执行 |
| **补充尽调** | 核心事实有 UNVERIFIED/CONFLICT，或核心类别 STALE |
| **暂缓** | 有时点性障碍（诉讼在办/认证在办/政策待明） |
| **淘汰** | 命中任一红旗 |

## 5. 红旗（一票淘汰，须 VERIFIED 证据）
命中以下任一即淘汰：OFAC SDN / BIS Entity List / UFLPA 涉疆清单；ITC 337 在案；未和解批量商标/专利诉讼；强监管品类缺强制认证；主体无法核验/空壳；产品召回史无整改；实控人严重失信/刑事；明确数据造假。
> 仅 WEAK 指向红旗时 → 结论「补充尽调」，并把核实该红旗列为第一优先问题。

## 6. 最小交付清单（快路径）
- `00_brief.md` 身份卡（锁死「查的是谁」+ 排除同名实体）
- `10_evidence_ledger.csv`（≥3 条核心事实，身份与 1 个核心渠道尽量 VERIFIED）
- `50_report.md`（一档决策 + 身份 + 核心证据 + 最大不确定项）
- 校验：`ledger_check.py` → 看决策上限提示
